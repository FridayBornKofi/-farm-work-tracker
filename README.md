Farm Work Tracker

A simple farm work time tracker for recording daily working hours.

Features

* Sign up and log in
* Farm number, optional
* Record work date
* Record work start time
* Record break start
* Record break resume
* Record work closing time
* Automatically calculate working hours
* Optional hourly pay
* Automatically calculate earnings
* Daily, monthly and total hours
* Records saved online
* Each user’s records are kept separate

How to use

1. Create an account.
2. Log in.
3. Enter your work details.
4. Tap Add Work Day.
5. The app calculates your working hours automatically.
6. Your record is saved to your account.

Example

If you work:

* Start: 08:00
* Break: 12:00
* Resume: 13:00
* Close: 17:00

The app records:

8 hours worked

Purpose

The Farm Work Tracker is designed to make it easy for farm workers to keep track of their hours and earnings without having to write everything down manually.

Technology

* HTML
* JavaScript
* GitHub Pages
* Supabase
* Supabase Authentication
* Supabase Database

Privacy

Users must log in to access their records. Work records are associated with the user’s account.
